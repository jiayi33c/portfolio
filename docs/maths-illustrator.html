Scientific Diagram Illustrator

Scientific Diagram Illustrator is an education-focused system for turning typed or uploaded maths and physics questions into worked explanations, similar practice questions, and visual support. Its main technical point is that diagrams are generated from mathematical and physical structure, not from a vague visual prompt alone.

Beyond Generic Image Generation

Ordinary diffusion images can look polished while getting geometry wrong. This project uses model reasoning to identify the construction first, then renders geometry through GeoGebra so labels, intersections, midpoints, perpendiculars, and segment relationships remain tied to the problem.

How It Works

The system reads the question, solves it, decides whether a diagram is useful, and chooses the right visual path. Geometry questions become structured GeoGebra commands, while non-geometry visual problems such as area, graphs, spatial reasoning, or physics scenarios can be routed through constrained illustration prompts derived from the solved question.

Understand

Parse typed text or an uploaded question image and recover the mathematical intent.

Solve

Produce a worked explanation, final answer, and similar practice questions.

Construct

Translate geometry into GeoGebra commands or create a constrained visual prompt.

Export

Show diagrams on the webpage and embed snapshots into the Word report.

Project Output

The system produces a worksheet-style result page and report that combine problem understanding, reasoning, diagram generation, and practice-question creation.

  • Recognized question text
  • Step-by-step worked solution
  • Final answer
  • Interactive GeoGebra diagram where applicable
  • Three related practice questions
  • Downloadable Word report with embedded diagram snapshots

Why It Matters

The key idea is to separate reasoning from visual rendering. Instead of relying on a generic diffusion model to directly generate a scientific diagram, the system first interprets the mathematical or physical structure of the problem, then renders the diagram as a constrained technical object.

This makes the final visual more useful for learning: it is designed to support the actual question, preserve important geometric or physical relationships, and avoid producing an image that only loosely resembles a textbook illustration.
